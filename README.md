# Dynamic Wumpus Logic Agent

## Overview
This project implements a knowledge-based agent that navigates a Wumpus world using propositional logic and resolution.

## Features
- Dynamic grid environment
- Random hazards (Pits + Wumpus)
- Logical inference using resolution
- Safe path decision making

## Technologies
- Python
- Propositional Logic
- Resolution Algorithm

## How to Run
1. Clone repo:
   git clone https://github.com/yourusername/wumpus-agent

2. Run:
   python main.py

## Output
- Displays agent position
- Shows percepts (Breeze/Stench)
- Prints total steps
